# ССЫЛКИ НА КОД ДЛЯ ПРИЕМНИКА И ПЕРЕДАТЧИКА
- Приемник (CubeSat): https://github.com/Kolya080808/predprof_25-26/blob/main/%D0%9F%D1%80%D0%BE%D0%B3%D1%80%D0%B0%D0%BC%D0%BC%D0%BD%D1%8B%D0%B9%20%D0%BA%D0%BE%D0%B4/receiver.ino

Код приемника реализует основную логику модуля наведения. Он постоянно прослушивает радиоканал. При получении команды "СТАРТ" от передатчика, модуль переходит в режим вещания и выполняет последовательность позиционирования.

Цикл работы включает проход по четырем режимам (горизонтальный, вертикальный, два диагональных). В каждом шаге модуль изменяет угол на 10 градусов, ждет 3 секунды и отправляет пакет данных с текущими координатами (Pitch/Yaw) и режимом работы обратно на пульт.

Управление сервоприводами осуществляется с проверкой допустимых углов (+-40°). Лазер включен постоянно при работе устройства.

- Передатчик (Пульт): https://github.com/Kolya080808/predprof_25-26/blob/main/%D0%9F%D1%80%D0%BE%D0%B3%D1%80%D0%B0%D0%BC%D0%BC%D0%BD%D1%8B%D0%B9%20%D0%BA%D0%BE%D0%B4/transmitter.ino

Код передатчика реализует пульт управления. По нажатию кнопки он отправляет команду на запуск сканирования модулю CubeSat. После отправки команды передатчик переходит в режим прослушивания и выводит в Serial порт все полученные пакеты телеметрии (текущие углы и режим) для контроля работы системы.
