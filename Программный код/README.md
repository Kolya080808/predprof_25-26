# ССЫЛКИ НА КОД ДЛЯ ПРИЕМНИКА И ПЕРЕДАТЧИКА
- Приемник (CubeSat): https://github.com/Kolya080808/predprof_25-26/blob/main/%D0%9F%D1%80%D0%BE%D0%B3%D1%80%D0%B0%D0%BC%D0%BC%D0%BD%D1%8B%D0%B9%20%D0%BA%D0%BE%D0%B4/receiver.ino

Алгоритм работы:

1. Задает переменные и настройки:
   - Подключает библиотеки для радио и моторов.
   - Назначает пины: 2 (лазер), 3 и 5 (сервомоторы).
   - Задает адреса для радиосвязи («CMD01» для приема, «DATA1» для отправки).
   - Создает структуру TelemetryPacket — «коробку», в которую будут упаковываться данные для отправки.

2. Создает вспомогательные функции:
   - setPosition — управляет сразу двумя моторами (наклоном и поворотом).
   - sendTelemetry — упаковывает текущие углы и режим в пакет и отправляет его по радио.
   - performStep — делает один шаг: сдвинуть моторы -> отправить отчет -> подождать 3 секунды.
   - runScanSequence — содержит сценарий движений: набор циклов для прохода по горизонтали, вертикали и двум диагоналям.

3. Настраивает устройство (setup):
   - Включает лазер (он горит постоянно).
   - Подключает моторы и ставит их в центр.
   - Запускает радиомодуль на прослушивание команд.

4. Слушает эфир (loop):
   - Постоянно проверяет, пришло ли сообщение по радио.
   - Читает сообщение в переменную messange.

5. Выполняет команду:
   - Если пришло слово "start" И программа еще не запущена:
     1. Включает блокировку (isRunning = true).
     2. Запускает функцию runScanSequence (моторы начинают выполнять 4 вида движений по очереди, отправляя отчеты).
     3. После завершения всех движений снимает блокировку и снова ждет команду.
    


- Передатчик (Пульт): https://github.com/Kolya080808/predprof_25-26/blob/main/%D0%9F%D1%80%D0%BE%D0%B3%D1%80%D0%B0%D0%BC%D0%BC%D0%BD%D1%8B%D0%B9%20%D0%BA%D0%BE%D0%B4/transmitter.ino

Алгоритм работы:

1. Задает переменные и настройки:
   - Подключает библиотеки SPI и RF24.
   - Назначает пины: 9 и 10 (для радио), 2 (для кнопки).
   - Задает адреса: «CMD01» (куда отправлять команды) и «DATA1» (откуда принимать данные).
   - Создает переменные для обработки нажатия кнопки (антидребезг).
   - Создает структуру TelemetryPacket — «коробку», в которую будут приниматься данные от модуля.

2. Настраивает устройство (setup):
   - Запускает Serial-порт для вывода информации на компьютер.
   - Настраивает пин кнопки как вход.
   - Запускает радиомодуль, ставит низкую мощность и скорость 1 Мбит/с.
   - Открывает каналы связи и сразу начинает слушать эфир.

3. Проверяет кнопку (в цикле loop):
   - Считывает состояние кнопки.
   - Если кнопка нажата И состояние изменилось (была не нажата):
     1. Проверяет время для защиты от ложных срабатываний (антидребезг).
     2. Останавливает прослушивание эфира (переходит в режим передачи).
     3. Отправляет команду "start" роботу.
     4. Если отправка не удалась, пишет ошибку в монитор порта.
     5. Снова включает режим прослушивания эфира.

4. Принимает данные (в цикле loop):
   - Проверяет, пришло ли что-то по радио.
   - Если данные есть:
     1. Читает их в структуру TelemetryPacket.
     2. Выводит полученные параметры (ID, режим, углы наклона и поворота) в монитор порта компьютера.
