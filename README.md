## Отчеты по ролям

### Программист:

- Приемник (CubeSat): 

Код приемника в данный момент реализует простейшую приемную станцию. Он постоянно прослушивает радиоканал, принимает входящие пакеты, расшифровывает их и выводит полученные значения в последовательный порт.

После успешного приема пакета приемник формирует и отправляет подтверждение (ACK), содержащее ID устройства и статус приема. Это обеспечивает синхронизацию между передатчиком и приемником и подтверждает корректность обмена данными.\

Приемник в данный момент используется для проверки работы радиоканала, расшифровки сообщений и подтверждения приема данных в рамках этапа тестирования программной части проекта.


- Передатчик:

В коде для передатчика подключаются библиотеки SPI и RF24, необходимые для управления радиомодулем NRF24.\
Далее объявляются глобальные переменные и структуры, такие как канал передачи (`const byte address`), уникальный идентификатор устройства (`const uint8_t DEVICE_ID`) и структура пакета (`struct Packet`), содержащая ID устройства, углы наклона (`pitch`), поворота (`yaw`) и режим работы.

Также используется структура `AckPacket`, предназначенная для приема подтверждения от приемника.\

Функция `sendPacket` формирует пакет данных, передает его по радиоканалу и ожидает подтверждение от приемника (ACK). Это позволяет избежать работы «по таймингам» и гарантирует, что данные были успешно приняты и расшифрованы.\

Далее реализованы функции `waitModeNGoBack`, `horizontalScan`, `verticalScan`, `diagonalScan1` и `diagonalScan2`, которые соответствуют режимам работы по техническому заданию (возврат в начальную точку, горизонтальный, вертикальный и два диагональных скана).\

В функции `setup` происходит инициализация радиомодуля и вывод логов в последовательный порт.
В `loop` данные режимы последовательно вызываются с задержкой 3 секунды, как указано в ТЗ.
