### Программист:

- Передатчик:

В коде для передатчика подключаются библиотеки SPI и RF24, для управления радио. Далее идут глобальные переменные и структуры, такие как канал (`const byte address`), ID устройства (`CONST uint8_t DEVICE_ID`) и структура самого пакета, который будет передан на приемник, основное устройство (`struct Packet`).
Далее идет объявление функции `sendPacket`, которая собственно и передает сообщения, достаточно лишь ввести режим работы и углы (`pitch` и `yaw`). Она задает переменной packet переданные функции переменные `pitch`, `yaw`, `mode` (то есть углы и режим) и ID устройства, после чего отправляет по радио пакет и логирует то, что было передано.
Далее идут функции `waitModeNGoBack`, `horizontalScan`, `verticalScan`, `diagonalScan1` и `diagonalScan2`, которые отправляют данные по техзаданию (то есть сначала движение в точку (0;0), далее горизонтальный, вертикальный и два диагональных скана, и возвращение в точку (0;0)).
Далее идет инициализация модулей (в данном случае только радио), логирование при успешной инициализации.
Ну и void loop(), где все функции вызываются каждые 3 секунды.
